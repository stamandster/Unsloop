# Quantitative and Data Evidence

Read this file when writing or review depends on numbers, calculations, datasets, spreadsheets, tables, charts, forecasts, measurements, survey results, or statistical claims.

## Establish data provenance

Record the dataset or source version, owner, locator, date range, population, unit of observation, fields used, filters, exclusions, transformations, missing-data treatment, and access boundary. Separate raw inputs, user-provided values, derived values, estimates, forecasts, and illustrative numbers.

## Verify the claim

For each material numerical claim:

1. identify the exact numerator, denominator, unit, period, population, and comparison baseline;
2. trace it to source fields or an explicit calculation;
3. reproduce the calculation with an authorized deterministic tool when practical;
4. check rounding, sign, scale, currency, timezone, inflation, unit conversion, percentage versus percentage-point language, and cumulative versus point-in-time meaning;
5. compare prose, table, chart, caption, and summary values;
6. record uncertainty, sampling, model, and data-quality limits; and
7. mark stale or changed inputs for recalculation.

Use **Source-reported**, **Recalculated**, **Partially reproduced**, **Estimated**, **Illustrative**, **Disputed**, or **Not checked**. Recalculated means the stated transformation was reproduced from inspected inputs; it does not validate the source data or method.

## Review analysis and visuals

Check whether the method fits the question, important groups or periods were excluded, axes or scales distort comparison, totals reconcile, labels and units are present, uncertainty is visible, and causal language exceeds the design. Do not infer statistical or scientific validity from a polished chart.

When analysis requires specialist judgment, preserve the calculation and route method validity to a qualified analyst. Never invent missing data, silently impute values, or choose a denominator because it strengthens the narrative.

## Return the result

Report the claim, source or dataset IDs, formula or transformation, reproduced result, displayed result, variance, status, confidence, limitations, and required correction. Keep executable formulas or code with the project only when authorized and useful for reproduction.
