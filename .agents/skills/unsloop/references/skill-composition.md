# Skill Composition and Authority

Read this file when Unsloop overlaps with a domain, research, data, coding, document-format, publishing, or organizational skill.

## Assign ownership

Use one shared user request and avoid duplicate intake. Assign responsibility by capability:

- **User and governing authority:** own purpose, meaning, permissions, consequential decisions, acceptance, and applicable policy.
- **Domain skill or qualified specialist:** owns domain rules, controlling terminology, substantive accuracy, and specialized safety or professional constraints.
- **Artifact skill:** owns file-format mechanics, layout, rendering, accessibility implementation, formulas, executable code, and format-specific verification.
- **Unsloop:** owns writing brief coherence, source and claim provenance, attribution, evidence boundaries, voice fidelity, editorial diagnosis, revision control, and readiness language.

Examples: a talk-writing skill governs outline and domain rules while Unsloop audits integrity and voice; a document skill owns DOCX rendering while Unsloop governs the prose; a spreadsheet skill owns formulas and workbook calculation while Unsloop checks the narrative claims against verified outputs.

## Compose the workflow

1. Identify every active skill or specialist role and the artifact each controls.
2. Reuse facts, decisions, and questions already resolved; do not make the user repeat intake.
3. Record the governing version, authority, and handoff boundary for each role.
4. Route a decision to the narrowest qualified owner.
5. Keep advice from one role Proposed until the governing owner accepts it when the change crosses responsibility boundaries.
6. Run format or domain validation before Unsloop represents the artifact as ready.
7. Return one coherent deliverable and a compact list of unresolved cross-role decisions.

## Resolve conflicts

Apply non-waivable law, safety, privacy, authorization, and governing policy first; then current user direction; then the controlling domain or artifact specification; then accepted project decisions; then Unsloop defaults. Do not let a prose preference silently override a formula, technical interface, doctrinal rule, policy owner, accessibility requirement, or legal review boundary.

When two specialists disagree, state the exact conflict, affected artifact range, evidence and authority of each position, decision owner, and safe interim state. Do not decide outside Unsloop's competence merely to keep drafting moving.

## Preserve handoff integrity

Record which role actually inspected, executed, rendered, approved, or verified each material property. Never convert another skill's fluent output into proof of domain accuracy, successful rendering, numerical correctness, safety, compliance, or approval.
