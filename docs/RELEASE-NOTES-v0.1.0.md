# Unsloop v0.1.0 prerelease

Unsloop is a portable Agent Skill for author-led writing and content work. This prerelease provides one shared method across **Review**, **Write**, and **Audit** for documents, websites, documentation systems, fiction, long-form nonfiction, research, and delivered writing.

## Included

- Progressive topic and writing briefs, evidence-based voice guidance, Style Direction, and controlled revision.
- Non-mutating Audit with source, claim, requirement, provenance, and writing-pattern findings. Prose style is not treated as proof of AI authorship.
- Website-content workflows for pages, page families, reader journeys, sampled sites, and enumerated corpora, with explicit coverage and validation limits.
- Portable project state for sustained fiction and nonfiction, plus user-selected response history or current-file overwrite.
- Project-local installation and optional links for Codex, Claude Code, Pi, and other compatible agent harnesses.

Start with the [README](https://github.com/stamandster/Unsloop/blob/v0.1.0/README.md) for use cases and installation, then see the [skill entrypoint](https://github.com/stamandster/Unsloop/blob/v0.1.0/.agents/skills/unsloop/SKILL.md) and [project specifications](https://github.com/stamandster/Unsloop/blob/v0.1.0/PROJECT.md).

## Release status

This is a documented foundation for controlled use and forward testing. The project validator and unit tests check structure and important contracts; cross-model calibration, inter-reviewer agreement, and the v1.0 validation work in the [roadmap](https://github.com/stamandster/Unsloop/blob/v0.1.0/ROADMAP.md) remain open. Scores are interpretive rather than validated measurement instruments.
