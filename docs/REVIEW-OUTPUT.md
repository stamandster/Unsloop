# Review Output Contracts

## Default: Unsloop Review

### Overall assessment

Give a short judgment of clarity, source integrity, writing consistency, specificity, and voice. State the evidence boundary when it affects confidence.

When an inferred or missing brief element materially shaped the review, add a compact **Brief assumptions** note. Do not recite settled fields or burden a simple review with an intake transcript.

### High-priority concerns

For each finding, include:

- **Passage:** a short excerpt or precise location
- **Problem:** the concrete issue
- **Why it matters:** effect on integrity, meaning, credibility, or voice
- **Evidence:** source comparison or textual pattern, when relevant
- **Severity:** Low, Moderate, High, or Critical
- **Suggested correction:** the smallest useful intervention

### Voice and style

Identify the few patterns with the largest effect. Include scores only when requested or when they materially clarify the review.

### What should remain unchanged

Name strong passages or habits worth preserving. Do not manufacture criticism to make the review appear comprehensive.

### Revised version

Include only when requested. If the user asks for both review and revision, keep the diagnosis distinct from the revised text.

## Unsloop Audit

Add these sections:

### Evidence boundary

List draft version, supplied sources, externally verified sources, inaccessible sources, and any similarity report used.

Record the writing goal and any consequential brief assumptions separately from the evidence corpus.

### Source map

| Draft location | Source | Relationship | Dependence score | Confidence |
|---|---|---|---:|---|

### Claim verification

Separate:

- verified support;
- overstatement or mismatch;
- secondary-source problems;
- claims that could not be checked.

### Integrity conclusion

Summarize supported findings and unresolved questions. Do not infer intent.

## Unsloop Write

For drafting, return the requested artifact first unless the user asks for process notes. Add a compact integrity note only when sources, uncertain claims, or attribution choices need attention.

If the result depends on consequential inferred or unresolved details about the goal, audience, prior knowledge, context, required content, or constraints, add a compact **Brief assumptions** note.

For revision, briefly state:

- what was preserved;
- what materially changed;
- which claims or citations still need user confirmation.

When matching the user's voice is material, also state:

- **Voice basis:** explicit instructions, current draft, and number/type of authorized samples used;
- **Target traits:** the few observable traits that materially shaped the result;
- **Confidence:** Low, Moderate, or High, plus any conflict or limitation.

## Score display

Use this compact form:

```text
Strengths: Specificity 4/5 · Authorial voice 3/5 · Source independence N/A
Risks: Redundancy 2/5 · Formulaicity 3/5 · Abstraction 2/5
Slop density: 2.3/5 — Mild
Source dependence: Not scored; no comparison source supplied
Voice fidelity: 4/5 · Confidence: Moderate · Basis: one same-genre sample plus current instructions
```

Never present the scores without enough commentary for the writer to understand what drove them.
